# 45^n + n が素数となる自然数 n

## 問題

45^n + n が素数となる自然数 n をすべて求めよ。

## 分かっていること（計算で確認済み）

- n = 2 のとき 45^2 + 2 = 2027 で、これは素数。
- n ≤ 10000 で素数になるのは n = 2, 3878, 9424 の 3 個だけ。
- n = 34 のとき
  45^34 + 34 = 13528815149 × 11966460332887293431597622052770191564909347991
  最小の素因数が 11 桁あり、5000 未満の素因数は 1 つもない。

素数判定は GMP（gmpy2 の is_prime）による確率的素数判定。

## 証明について

- 奇数 n、3 で割れる n、5 で割れる n は初等的に除外できる。
- 小さい素数で剰余類を覆う covering 型の証明は n = 34 で通らない。候補（偶数で 3 でも 5 でも割れない n）は n ≤ 2000 で 533 個あり、そのうち 112 個が 5000 未満の素因数を持たない（最初は 34, 92, 116, 124, 128, 176）。
- 一般の証明は未確認。この問題は未解決問題として公開する。

## 探索の状態

- n ≤ 100,000 の探索を実行中。候補は 6,478 個（小さい素数でふるった後）。2026-11-17 時点で 600 個まで確認済み、n = 2 以外に見つかったのは 3878 と 9424。

## 検証した誤った主張について

「n ≤ 10000 で 142 個ある」「45^9954 + 9954 = 1033498479634483787」という投稿があったが、どちらも誤り。45^9954 + 9954 は 16,457 桁の数で下一桁は 9 であり、19 桁で下一桁 7 のその数とは一致しない（64 ビット整数のあふれによる計算結果）。n = 9954 は小さい素数で割れるため、候補ですらない。
